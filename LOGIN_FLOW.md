# Prahari Netra Login Flow

- `/` is the animated India-map + satellite landing page.
- `ENTER WORKSPACE` opens `/login`.
- `/login` contains only the Admin/Ground Officer rank selection, password and Authenticate action.
- The login card is intentionally compact for a cleaner presentation layout.
- `EXIT SYSTEM` is fixed at the bottom-left corner of the login screen.
- Clicking `EXIT SYSTEM` clears the local Prahari session and returns to `/`, the animated India-map + satellite landing page.
- Admin login routes to `/admin`; Ground Officer login routes to `/officer`.
- Admin dashboard includes Ground Officer activity visibility.
