# Prahari Netra local camera recordings

These are local recorded sources used by the browser camera player.

- `city-traffic.mp4` — traffic / vehicle scene
- `vehicle-highway.mp4` — multi-vehicle roadway scene
- `pedestrian-corridor.mp4` — pedestrian scene
- `crowd-overhead.mp4` — overhead pedestrian scene
- `frost-path.mp4` — cold-weather person scene
- `thermal-analysis-view.mp4` — derived false-colour thermal-style analysis view from the cold-weather recording

The thermal-analysis file is a visualization derived from RGB footage; it is **not** a genuine infrared sensor recording. Replace it with a real thermal-camera recording when available.
