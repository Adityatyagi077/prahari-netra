# prahari-netra
# 🛡️ PRAHARI NETRA

### AI-Powered Tactical Surveillance & Command Platform

> A unified command-and-control platform designed to combine live surveillance, AI-assisted target analysis, operational mapping, evidence capture, and system monitoring into a single tactical interface.

---

## 🚀 Overview

**Prahari Netra** is an AI-enabled surveillance and tactical command platform that brings multiple operational capabilities together in one centralized interface.

The platform is designed around a command-center workflow where operators can:

- Monitor operational sectors through an interactive map
- Observe connected camera feeds
- Receive AI-assisted target classifications
- Monitor live phone-based field feeds
- Track incidents and operational activity
- Capture and manage evidence
- Monitor subsystem readiness and health
- Manage access and audit activity

The goal is to reduce fragmented monitoring and provide operators with a **single operational picture**.

---

## ✨ Key Capabilities

### 🗺️ Interactive Operations Map

A fully interactive operational map provides a geographical view of monitored sectors and system activity.

Features include:

- Sector visualization
- Sensor status
- Operational state indicators
- Threat-related information
- Interactive map controls
- Tactical monitoring workflow

---

### 📡 Camera Surveillance

Centralized camera monitoring allows operators to access multiple surveillance feeds from one interface.

The platform supports:

- Multiple camera feeds
- Live monitoring interface
- Camera status
- Surveillance recordings
- Camera-specific operational views

---

### 🧠 AI-Assisted Target Analysis

Prahari Netra integrates an AI/ML service for computer-vision-assisted analysis.

The ML service includes:

- YOLO-based object detection
- Target inference
- Confidence information
- AI classification workflow
- Integration with the operational dashboard
